# Milky's Diary

Milky's personal growth diary, ready for GitHub Pages.

## Deploy
1. Create a public GitHub repository named `milky-diary` under `keyu-wan`.
2. Upload `index.html` to the repository root.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Visit https://keyu-wan.github.io/milky-diary/ after publishing.

## Important
This is a static HTML site. Editing controls and saved entries use the browser's local storage and **are not synced** between visitors/devices. Visitors may edit their own local copy; they cannot modify the repository. Do not use the page to store private information. Owner-only editing and cloud synchronization require a backend, authentication, and security rules.
